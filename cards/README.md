# 카드 이미지 출처와 라이선스

한솔 명리 무료 타로의 메이저 아르카나 22장은 1909년 **Rider-Waite-Smith** 덱(Pamela Colman Smith 작, 1951년 사망)의 메이저 아르카나입니다.
퍼블릭 도메인(사후 70년 경과)이며, Wikimedia Commons에서 받아 사이트 내부 정적 파일로 저장했습니다(외부 핫링크 없음).

해상도: 높이 660px WebP (원본 축소본), 파일: `00.webp` ~ `21.webp`
